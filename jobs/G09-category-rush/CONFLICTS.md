# Research conflicts and explicit choices

| Issue | Evidence disagreement or silence | Chosen behavior and reason |
|---|---|---|
| Three or four rounds | Hasbro 2003, GameRules and UltraBoardGames use three; F6795 uses four. | Default three, selectable 1–5. Marked as a house format, not an edition claim. |
| Keep or replace the list | Hasbro 2003 keeps a list for all rounds; F6795 lets players choose a new list. | Replace each round. Selecting from letter-compatible original prompts avoids empty offline bot banks. |
| Timer variants | Hasbro 2003 names 180/150/120 seconds; GameRules says electric timers can use 1/2 minutes; TheRuleBook headline says two minutes while its component list says three. | Configurable 30–180 seconds. The publisher establishes the 180-second baseline; shorter choices are house settings. |
| Challenge author voting | Hasbro, GameRules and licensed Cactus edition include the author and exclude that vote only on a tie; TheRuleBook's later “organized” protocol excludes the author throughout and accepts ties. | Publisher protocol. Unsupported organized-play assertions do not override the publisher. Abstentions and residual ties are explicitly deterministic software extensions. |
| Several equivalent-answer authors | Physical rules discuss one challenged player, while the core groups normalized duplicates and can therefore have several authors. | Core group resolution removes equivalent-answer authors' ballots on a tied group vote. Duplicates still score zero regardless, so this extension does not rescue a collision. |
| Proper-name letter position | Hasbro and GameRules require the qualifying name first in the written answer; Wikipedia says any proper-name component or a middle initial can qualify. | Require the written meaningful first character to match. Follow publisher wording. |
| Bonus point scope | Older rules limit bonuses to proper names/titles; F6795 permits a broader repeated-letter compound answer; TheRuleBook presents two-point alliteration as base scoring. | One point only. Bonus variants are documented and excluded; no accidental rewards for adjective padding. |
| Self-reuse penalty | Publisher prohibits the same answer twice but does not specify which occurrence to strike; GameRules says one instance remains valid. | Cancel every occurrence for that player's sheet. Explicit house clarification removes order advantage. |
| Final equal totals | Older rules add a tiebreak round; F6795 does not explain a final tie; the separate Categories game shares victory. | Shared victory after configured rounds. Bounded completion takes precedence over an indefinitely repeated tiebreak. |
| Excluded letters | Wikipedia and Game Room Legends agree on Q/U/V/X/Y/Z. TheRuleBook both excludes them and later says Q/X/Z are equally likely on that die. | Use ABCDEFGHIJKLMNOPRSTW. TheRuleBook's contradictory tournament passage is rejected. |
| Semantic completeness | A category's curated answer bank cannot enumerate every defensible human answer. | Human group voting decides membership; bots abstain when they do not recognize an answer. Never treat absence from a bank as invalidity. |
| Local naming and context | “Vegetable” is culinary, not a claim about botanical fruit; some tools or foods have regional names. | Prompts intentionally use ordinary culinary/contextual meanings, established names count, and groups may accept additional real examples. |

Research hand checks also found two repairable authoring problems before acceptance: “badminton” was removed from the ball-and-net category because its projectile is a shuttlecock; a toy “dog” was made explicit as “pull-along dog.” Compact duplicates such as “potholder”/“pot holder” were corrected. These are content corrections, not rule conflicts.

## Round-2 source accuracy

Serious Eats calls asafoetida resin a tree product; Good Food describes its giant-fennel source. Only their agreed culinary-seasoning membership is used; the contradictory anatomy claim is not adopted. USDA's culinary spice plant-part list includes fruits/arils among its seed examples, so it supports culinary use only and is not treated as an authoritative botanical seed-classification dataset. Exact reads/URLs and limits are in SOURCES.md and SPOTCHECKS-R2.md.
